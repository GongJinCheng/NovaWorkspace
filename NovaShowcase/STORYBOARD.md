# Nova v2.6 Showcase Storyboard

## Creative Direction

- Tone: calm, professional, developer-productivity focused.
- Visual system: black / deep navy background, electric blue accents, glass cards, grid lines.
- Messaging: Nova is not just an editor. It is a local-first AI workspace that connects docs, AI, todos, and project progress.

7. Project Dashboard
   - Docs

   - AI status

8. Version Safety
   - Auto-save
   - Snapshots

9. Nova Workspace
   - Build your local AI workflow
