# Nova v2.5.0 - 项目级 Todo 隔离版

本版本重点修复 Todo 数据模型：待办任务不再作为全局数据混在一起，而是按当前工作区/项目单独保存。

## 新增与调整

- Todo 数据按工作区隔离，保存到当前项目的 `.nova/todos.json`。
- 无工作区时仍保留全局 Todo 兜底，不影响空状态或临时使用。
- 主进程 Todo Store 支持多工作区缓存，避免切换项目后读到旧项目任务。
- Todo IPC 全链路支持 `workspaceRoot` 参数。
- 渲染层 Todo API 自动读取当前工作区，不需要每个页面手动传参。
- 首页今日待办、逾期统计、完成统计只显示当前工作区数据。
- Todo 中心只显示当前工作区任务和分类。
- Ctrl+K 搜索 Todo 时只搜索当前工作区任务。
- 文件管理器 AI 生成待办时写入当前工作区的 `.nova/todos.json`。
- Todo 来源文档新增 `sourceRelativePath`，项目文件夹迁移后仍可定位来源文档。

## 数据位置

现在每个工作区会拥有自己的待办数据：

```text
当前工作区/
└── .nova/
    └── todos.json
```

无工作区时才会使用旧的应用级全局数据：

```text
AppData/Roaming/Nova/todos.json
```

## 验证建议

1. 打开项目 A，创建几个待办。
2. 打开项目 B，确认不会看到项目 A 的待办。
3. 在项目 B 生成 AI 待办，确认只写入项目 B。
4. 切回项目 A，确认项目 A 待办仍然存在。
5. 查看两个项目目录下是否分别出现 `.nova/todos.json`。
