# Nova v2.7.0 - 模板系统

本版本新增 Markdown 文档模板能力，让 Nova 在新建文档时不再只是空白文件，而是可以快速生成结构化内容。

## 新增功能

- 新增内置 Markdown 模板：
  - 空白文档
  - 产品需求文档 PRD
  - 会议纪要
  - 技术方案
  - 开发计划
  - Bug 记录
  - 周报
  - 项目复盘
  - 学习笔记
  - AI Prompt
- 文件管理器「新建文档」改为模板选择流程。
- 支持模板变量自动替换：
  - `{{title}}`
  - `{{projectName}}`
  - `{{date}}`
  - `{{datetime}}`
- 项目概览页新增「从模板创建」快捷区。
- Ctrl+K 命令面板新增模板创建命令，可直接搜索 PRD、会议纪要、技术方案、周报等模板。
- 从模板创建后会自动写入 Markdown 内容并打开到编辑器。

## 使用方式

### 文件管理器

1. 打开工作区
2. 点击「新建文件」
3. 选择模板
4. 输入文件名
5. Nova 自动生成并打开文档

### 项目概览页

在「从模板创建」区域点击常用模板，即可快速创建结构化文档。

### Ctrl+K

按 `Ctrl + K`，输入：

- PRD
- 会议纪要
- 技术方案
- 周报
- 项目复盘

即可通过命令面板创建模板文档。
