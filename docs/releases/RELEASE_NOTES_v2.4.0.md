# Nova v2.4.0 - 全局搜索与命令面板增强

本版本重点升级 `Ctrl+K` 全局搜索，把它从页面跳转入口扩展为 Nova 的超级命令面板。

## 新增功能

- `Ctrl+K` 支持搜索当前工作区文件名。
- 支持搜索 Markdown / 文本 / 代码文件正文内容，并显示命中片段和行号。
- 支持搜索 Todo 标题和描述。
- 支持通过命令面板快速执行：
  - 打开工作区
  - 新建文档
  - 新建待办
  - 打开设置
  - 打开 AI 助手
  - AI 总结当前文档
  - AI 根据当前文档生成待办
  - 问当前文档
  - 保存当前版本
  - 查看版本历史
- 命令面板支持键盘操作：
  - `↑ / ↓` 选择
  - `Enter` 执行
  - `Esc` 关闭

## 优化内容

- 全局搜索结果按“命令 / AI 命令 / 文档命令 / 文件 / 文档内容 / 待办”分组展示。
- 搜索面板宽度和高度优化，更适合显示多类型结果。
- 从搜索结果打开文件时，会自动切到文件管理器并打开对应文件。
- 从搜索结果打开 Todo 时，会自动切到待办中心并打开任务详情。

## 注意事项

- 搜索范围为当前打开的工作区。
- 为避免大型项目卡顿，搜索会忽略 `node_modules`、`.git`、`.nova`、`dist`、`release`、`build` 等目录。
- 正文搜索主要覆盖 Markdown、TXT、JSON、TS/JS、CSS、HTML、YAML 等文本文件。
