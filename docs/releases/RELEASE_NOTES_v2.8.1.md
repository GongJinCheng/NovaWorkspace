# Nova v2.8.1 - 编辑状态恢复修复版

本版本针对 v2.8.0 导出系统上线后可能出现的编辑器状态异常做稳定性修复。

## 修复

- 修复导出 HTML / PDF 后 Monaco 编辑器可能失去焦点或编辑状态异常的问题。
- 导出完成后会主动恢复编辑模式、布局和可编辑状态。
- PDF 导出隐藏窗口改为不可聚焦，并增加加载/打印超时兜底，避免隐藏打印窗口异常影响主窗口。
- 如果导出前处于预览模式，导出后会回到编辑模式，避免用户误以为编辑功能失效。

## 验证建议

1. 打开 Markdown 文档并编辑。
2. 导出 HTML。
3. 回到编辑器继续输入。
4. 导出 PDF。
5. 回到编辑器继续输入。
6. 在预览/分屏模式下导出，再确认可以继续编辑。
