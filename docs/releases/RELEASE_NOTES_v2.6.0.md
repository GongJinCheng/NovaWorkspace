# Nova v2.6.0 - 项目概览页

本版本新增项目概览页，把当前工作区升级为可观察、可推进的项目控制台。

## 新增功能

- 新增侧边栏「项目概览」页面。
- 为每个工作区自动创建 `.nova/project.json`。
- 支持编辑项目名称和项目描述。
- 显示当前项目路径、更新时间和 AI 状态。
- 新增项目统计：
  - Markdown 文档数量
  - 总文件数
  - 未完成任务
  - 今日到期任务
  - 逾期任务
  - 历史版本数量
- 新增最近文档列表，点击可直接打开 Markdown 文档。
- 新增最近活动列表，聚合文档编辑、待办任务和版本历史。
- 新增项目快捷操作：
  - 新建文档
  - 新建待办
  - 打开文件管理
  - 打开 AI 助手
- 新增项目级 AI 入口：
  - 总结项目
  - 生成计划
- Ctrl+K 命令面板新增「打开项目概览」。

## 数据说明

项目元信息保存在当前工作区：

```text
当前工作区/.nova/project.json
```

Todo、版本历史和项目统计均基于当前工作区独立计算。
