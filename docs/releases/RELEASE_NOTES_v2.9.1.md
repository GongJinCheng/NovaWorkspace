# Nova v2.9.1

## 改进

- 重新设计待办中心时间轴看板：时间分组保持单行横向滚动，空分组改为轻量化占位，避免小屏或任务较少时卡片换行、重复显示“暂无任务”导致界面别扭。
- AI 助手增加图片输入能力判断：当当前模型不支持视觉/多模态输入时，不再把 `image_url` 直接发送给接口，而是在聊天区友好提示“当前模型不能识别图片”。
- 历史会话中如果包含图片，切换到纯文本模型后会自动省略历史图片，避免后续纯文本提问继续触发图片结构报错。
- 优化图片相关错误文案，将接口返回的 `unknown variant image_url`、`expected text` 等底层错误转换为可理解提示。

## 验证
