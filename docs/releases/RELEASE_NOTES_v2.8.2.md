# Nova v2.8.2 - 快捷键初始化修复

本版本修复应用启动后第一次按 `Ctrl+K` 可能无法唤起命令面板的问题。

## 修复

- `Ctrl+K` 改为启动阶段立即注册，并使用 capture phase 监听，避免被输入框、编辑器或页面局部事件吞掉。
- 同时在 `document` 和 `window` 上注册全局快捷键，提高 Electron 启动初期的稳定性。
- 统一快捷键大小写判断，兼容不同键盘状态。
- 暴露 `window.__openCommandPalette` 兜底入口，侧边栏搜索和后续测试都可以复用。
- 保持 `Ctrl+P` 仍然只作为文件快速打开，不改变现有行为。

## 验证建议

1. 完全退出 Nova 进程。
2. 重新启动 Nova。
3. 不点击任何页面，直接按 `Ctrl+K`。
4. 确认命令面板可以立即打开。
5. 再测试 `Ctrl+P`，确认快速打开文件仍然正常。
