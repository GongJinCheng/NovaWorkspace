## Bug 修复 - 首页"打开项目"弹窗三次

- **根因**：`home/index.ts` 的 `bindQuickActions()` 在每次 `initHomePage()` 被调用时都会重复绑定 click 事件
  - router 对 files/ai/todo/home 每次导航都调用 init，用户多次访问首页后事件监听器叠加
  - 点击一次"打开文件夹"按钮会触发 N 次 `openWorkspacePicker()`，进而弹出 N 个文件选择窗口
- **修复**：在 `home/index.ts` 添加 `let quickActionsBound = false` 模块级守卫变量，在 `bindQuickActions()` 开头检查并提前返回
- **文件**：`src/renderer/pages/home/index.ts`，修改 2 处（添加变量 + 函数守卫）
- **验证**：`npm run build` 构建通过，零报错

## Bug 修复 - AI 功能（改写选中/生成大纲/总结/问文档）显示 think 标签内容

- **根因**：`editor-manager.ts` 的 `rewriteSelectedMarkdown`、`showMarkdownAiResult` 调用处直接使用了 AI 原始返回文本，未剥离 `<think>...</think>` 思考过程块，导致思考内容直接显示在编辑器或弹窗里
  - `rewriteSelectedMarkdown`：改写结果直接写入 Monaco 编辑器
  - 生成大纲/Markdown 总结/问当前文档：结果直接传给 `showMarkdownAiResult` 展示
- **修复方案**：
  1. 将 `stripReasoningBlocks` 函数提升到 `src/shared/utils/ai-capabilities.ts` 作为共享导出函数
  2. `editor-manager.ts` 引入并在三处（改写/大纲/总结/askdoc）使用
  3. `ai/index.ts` 同样改为从 shared 引入，删除本地重复定义（DRY 原则）
- **设计原则**：只有 AI 助手页面对话中保留并渲染思考过程（`<details>` 折叠），其他所有 AI 功能均剥离思考内容
- **修改文件**：
  - `src/shared/utils/ai-capabilities.ts`：新增 `export function stripReasoningBlocks`
  - `src/renderer/pages/files/editor-manager.ts`：import + 三处调用
  - `src/renderer/pages/ai/index.ts`：改用 shared 版，删除本地定义
- **验证**：`npm run build` 构建通过，零报错
